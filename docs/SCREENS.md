# Mo-Tix 화면 · Screens

42dot의 공식 Pleos Connect 에뮬레이터(v2.1.0, 2560 × 1440)에서 캡처했습니다. 차량 위치는 서울 성수동
(`adb emu geo fix 127.0557 37.5446`), 기어와 속도는 Pleos Connect Virtual Console로 설정했습니다. 각 화면의 왼쪽 3분의
1은 Pleos 주행 화면(Driving view)이고, Mo-Tix는 앱 영역에 있습니다. 상영 시간·좌석·결제는 시뮬레이션입니다(README
참고). 영화 이미지의 권리는 각 권리자에게 있습니다.

Captured on 42dot's official Pleos Connect emulator (v2.1.0, 2560 × 1440), with the car placed in Seongsu-dong, Seoul,
and the gear and speed set through the Pleos Connect Virtual Console. The left third of each capture is the Pleos
Driving view; Mo-Tix is in the app area. Showtimes, seats and payment are simulated (see the README). Film artwork
belongs to its rights holders.

## 제출용 release 빌드(API 키 미포함) · The release build, no keys

화면입니다. 캐시 모드로 저장된 서울 상영작 화면에서 시작합니다.

Version 1.1.0, the release APK built with no API keys in it (`-PnoKeys`), on the emulator after a factory reset
(Korean, the light display mode it ships with). It opens in cached mode on the saved Seoul lineup.
